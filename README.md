The ddr. website is a [Next.js](https://nextjs.org/) app.

## Getting Started

- Set a Radio Cult API key in `.env.local`.

  ```
  NEXT_PUBLIC_RADIO_CULT_API_KEY=your_api_key
  ```

- `npm install`
- `npm run dev`

## Deployment

The app is deployed automatically on any changes in the `main` branch.
